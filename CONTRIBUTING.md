# Mitwirken bei Archiv des Vergessens V2 📜

Vielen Dank für dein Interesse, zum Projekt **Archiv des Vergessens V2** beizutragen! Wir freuen uns über jede Unterstützung — sei es durch Bug-Reports, Ideen für neue Generatoren, Balancing-Anpassungen oder Code-Beiträge.

---

## 🛠️ Entwicklungs-Setup

1. **Repository klonen**:
   ```bash
   git clone https://github.com/Grimoire-Interactive-Studio/Archiv-des-Vergessens-V2.git
   cd Archiv-des-Vergessens-V2
   ```

2. **Abhängigkeiten installieren**:
   ```bash
   npm install
   ```

3. **Entwicklungsserver starten**:
   ```bash
   npm run dev
   ```

4. **Tests ausführen**:
   ```bash
   npm test
   ```

---

## 🚀 Pull Request Prozess

1. Erstelle einen eigenen Branch für dein Feature oder Bugfix:
   ```bash
   git checkout -b feature/mein-neues-feature
   ```
2. Achte darauf, dass alle Tests grün bleiben (`npm test`).
3. Commit deine Änderungen mit prägnanten Commit-Nachrichten.
4. Öffne einen **Pull Request** auf GitHub und beschreibe kurz deine Änderungen.
